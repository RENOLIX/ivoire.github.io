# Ivoire Natural Care

Landing page statique pour le shampoing solide Ivoire. Ouvrir `index.html` dans un navigateur ou publier la branche principale avec GitHub Pages.

Le formulaire reprend les champs et interactions du formulaire Darling (coordonnées, wilaya, commune, mode de livraison, adresse conditionnelle, quantité et validation du téléphone). Il est **visuel uniquement** : aucun service d’envoi ni clé Web3Forms n’est intégré. Les frais de livraison restent à confirmer.

Le logo transparent est tiré du logo remis par le client. La scène produit et les trois photos du rituel sont des visuels générés à partir de la maquette fournie. Le visuel produit original est conservé dans `assets/produit-ivoire.jpeg`.
